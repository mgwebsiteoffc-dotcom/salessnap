A clear workflow

From product selection to rollback.

Every campaign is queued through the same check-before-change process.

01

Select products

Search the Shopify catalog and select the products for this campaign. The current version supports up to 250 selected products per campaign.

02

Choose what to change

Set the price discount, optional product tag, and optional text to prepend to each product description.

03

Schedule the campaign

Choose the start and end in a timezone you select. The campaign is not applied before its start time.

04

Snapshot, apply, and review

The app saves original product and variant values before the first write. At the end time—or when you request an emergency restore—it checks current values and reports fields that need your attention.

Designed for safer rollbacks

Recovery should be part of the promotion plan.

Snapshots are saved before product writes. Rollbacks compare each current value with the campaign’s expected value, so changes that no longer match can be flagged instead of silently replaced.

Shopify product updates are not one atomic transaction across a whole campaign. Network failures or concurrent staff edits can result in partial changes or conflicts. Review the campaign status and snapshot history after every restore.

Good to know

Questions before your next sale?

Here’s what the current release does—and where you stay in control.

Which product changes can I schedule?

The current release supports a percentage price reduction, one added tag, and plain text prepended to the product description. Collection-wide selection, metafields, and product status changes are not available in this build.

Does rollback overwrite edits made by my team?

The app checks prices against the campaign’s sale values and removes only its description prefix. Unrelated tag values are preserved. If a value no longer matches, the app flags a conflict instead of restoring that field. Shopify does not provide a cross-product compare-and-swap transaction, so simultaneous edits can still race with a write.

Is an emergency restore instant or guaranteed?

No. Restore work is queued and checked product by product. Shopify API availability, access revocation, deleted products, and concurrent edits can prevent some values from being restored. Check the restore report and resolve any conflicts manually.

How long are snapshots retained?

In the current app configuration, completed or cancelled campaign snapshots and operational logs are purged after 90 days. Active or unresolved campaigns remain until resolved or the app is uninstalled.

Where do I install and see pricing?

Use the Shopify App Store button above. The install link opens the app’s official Shopify App Store listing when it is published. Pricing and availability will be shown there.
