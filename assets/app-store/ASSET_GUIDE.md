# SaleSnap brand and listing assets

- `salesnap-app-icon-1200.png` — 1200×1200, text-free square icon. Intended as Shopify App Store app icon.
- `salesnap-wordmark-900x180.png` — transparent wordmark for the marketing site and partner materials; don't substitute it for the app icon.
- `screenshots/01`–`04` — four distinct 1600×900, synthetic-demo desktop UI mockups. `screenshots/05-mobile-overview-900x1600.png` — responsive-layout mockup in portrait orientation; confirm the current listing upload dimensions in the Partner Dashboard. **None are captured from a running application. Do not submit them as final Shopify screenshots.** After backend setup, use a real development store, recreate the demo state in the deployed app, capture actual UI without browser chrome or private merchant data, and replace these mockups.

Shopify currently specifies a 1200×1200 app icon and 3–6 desktop screenshots at 1600×900 with alt text; its guidance also says to show mobile/POS experiences when relevant. The icon has no text, Shopify mark, or rounded outer corners. The screen mockups use only fictitious demo data and contain no merchant/customer PII. Review the listing rules again when submitting.
